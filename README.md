# Проект АнализТранзакций

## Описание:

Проект  АнализТранзакций -  это приложение для анализа транзакций, которые находятся в Excel-файле.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Demetra404/BankingApplicationAnalysis.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
